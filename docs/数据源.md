## mootdx (通达信 TCP 7709)

**职责：** 实时行情 + K线 + 五档盘口 + 逐笔成交

**优势：**
- TCP 二进制协议，不封 IP
- 延迟 ~50ms，比 HTTP 快 100 倍
- 46 字段返回（price, open, high, low, vol, amount, bid1~5, ask1~5）

**不支持：** PE, PB, ROE, 市值, 换手率（走腾讯财经或 tushare）

**已知 Bug：**
1. **frequency ≠ category** — `bars()` 参数名是 `frequency`，传 `category` 会被 `**kwargs` 静默吞掉，永远退化成日线
2. **BESTIP 空串 bug (0.11.x)** — 全新安装后 `Quotes.factory(market='std')` 可能抛 `ValueError: not enough values to unpack`。根因：`~/.mootdx/config.json` 的 `BESTIP.HQ` 初始是空字符串。**解决：显式传 server IP，不走 bestip**
3. **服务器会老化** — 官方 IP 列表不是永久有效的，需要维护备选服务器池
4. **海外 IP 不可用** — 通达信 TCP 协议走国内机房，海外环境全部超时。`tdx_client()` 会快速失败而非死等

**服务器池：**
```
119.97.185.59:7709 → 124.70.133.119:7709 → 116.205.183.150:7709
123.60.73.44:7709 → 116.205.163.254:7709 → 121.36.225.169:7709
123.60.70.228:7709 → 124.71.9.153:7709 → 110.41.147.114:7709
```

**频率映射表（mootdx 0.11.7 实测）：**
```
0=5分钟 1=15分钟 2=30分钟 3=60分钟 4=日线 5=周线 6=月线
8=1分钟 9=日线(默认) 10=季线 11=年线
```

**集成状态：** ✅ 已集成 (SourceManager, trust=动态)

## Tushare

**职责：** A 股 EOD 主数据源：日线、每日指标、股票元数据、指数、市场宽度、财务三表/指标、资金流和可用的龙虎榜汇总

**优势：**
- 官方 SDK，字段和交易日口径明确
- 支持按交易日批量拉取，适合全市场快照和历史学习基准
- 研究证据保留 provider、endpoint、data_date、fetched_at、coverage

**当前主备规则：**
- 只要接口支持、权限有效、数据日期和覆盖率满足用途，SourceManager 优先选择 Tushare
- 无权限、空结果、过期、覆盖不足或请求故障才走备用，并记录 `fallback_reason`
- Tushare 当前适配器按 EOD 语义使用；盘中实时、分钟线、盘口不能标成 Tushare 实时
- raw 日线由 Tushare 优先；qfq/hfq 继续使用具备复权能力的备用源

**当前问题：**
- 全市场最近三个完整交易日实测覆盖率约 99.84%~99.87%，不是 100%；部分股票缺日仍保留缺口
- 基本面按股票和报告期可能缺失；缺失不填零、不伪装成正面证据
- `suspend_d` 本次探测返回空结果；公告/新闻接口（`anns_d`、`news`、`major_news`）在当前账户返回无权限，研报/大宗交易样本为空，因此继续走原备用源；龙虎榜席位明细也未用汇总接口伪装

**集成状态：** ✅ 已集成（Tushare-first EOD；支持覆盖率/日期/备用原因审计）

## HiThink Financial API（同花顺官方）

**职责：** 标的名称/代码消歧、当前估值、涨跌停/炸板/连板/异动/热榜、龙虎榜，以及日线和财务数据的交叉验证。

**优势：**
- 官方 REST 契约，返回统一业务信封和 `request_id`，适合在适配器层做错误分类与审计。
- `thscode` 明确携带 SH/SZ/BJ 后缀，减少名称和纯六位代码造成的市场歧义。
- 特色数据结构化程度高，龙虎榜、涨停池和热榜不需要依赖网页解析。
- 2026-09-12 短时实测 40/40 成功，主要能力 P95 约 333–366ms；该结果只证明短时可用性，不替代交易日 canary。

**主备规则：**
- Tushare 继续作为盘后原始日线、历史财务、资金流和回放可知时点的真值层。
- HiThink 首先用于标的消歧、当前估值、特色数据和龙虎榜；Tushare/东方财富保留校验与降级。
- HiThink 日线和财务先处于 validator/fallback；未完成三个完整交易日的时间戳验证前，不能进入实时执行报价。
- 本地新鲜缓存始终优先；HiThink 失败、业务 `code != 0`、空数据或权限不足必须记录 `fallback_reason` 并沿用既有降级链。

**已知边界：**
- 当前不提供可直接证明交易所实时成交时间的分钟 K、逐笔、Level-2 或盘口能力。
- 快照在周末/节假日可能代表上一交易日，必须标记 EOD/previous-session，不能标记 `is_live=true`。
- 财务报表必须按 `period_end_ms`、`report_date_ms`、币种和合并口径对齐；`null` 不得补零。

**集成状态：** 🟡 适配器阶段完成后进入 shadow；逐能力通过样本门禁后再提升为 primary。

## 东方财富 (EastMoney) — 独有数据

**只能从东方财富获取的数据（其他源没有）：**
- 龙虎榜席位 + 全市场龙虎榜
- 限售解禁日历
- 融资融券明细
- 大宗交易
- 股东户数变化
- 分红送转
- 个股资金流向（分钟/日级）
- 行业板块排名
- 研报列表/PDF 下载
- 个股新闻

**防封铁律：**
1. 串行，不并发 — 绝对不对东财开多线程
2. QPS ≤ 2 — 每次间隔 ≥ 1s + 随机抖动
3. 复用 HTTP 会话（Keep-Alive）
4. UA + Referer 必须正常

**集成状态：** ✅ 已集成（原生适配器串行限流；失败时透明回退 Vibe）
