# 现有 Tushare 权限下的数据补全实施方案

状态：待 Luna 实施。目标：补齐 A 股历史K线、股票基础信息、多期财报与现有候选资金流，并证明真实消费者使用正确、可追溯的数据。使用现有账户权限，不新增会员或定时任务，不改选股公式、权重、阈值、候选数量策略或交易风险规则。

## 基线与边界

此前只读核验：2026-09-04 日线 5548 只，与 stock_basic 交集 5207 只；差集 341 只是待解释对象，不能直接认定全部漏采。交集中缺市值和换手各10只。日常同步回补3个交易日，未证明最长指标历史覆盖完整。财报接口当前主要 limit=1。隔离扫描300条决策、78条进入补齐、77条报价成功；报价成功不等于财报和资金流均完整。此前资金流顶层传播缺陷已修复，不得回退。

2000积分支持核心标准接口；实施前以当前 token 实测端点及频次，不输出凭据。不承诺每只股票都有8季财报或连续自然日日线。此次财务趋势仅补研究输入，不新增评分因子；学习规则维持原样。
