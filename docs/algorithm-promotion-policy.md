# 算法晋级门禁

本插件的算法变更只能先进入离线回放和影子运行，不能因为单日榜单好看就接管模拟成交，更不能直接接实盘。

## 1. 离线回放

- 使用同一批冻结的点时快照，baseline 和 candidate 必须共享交易日、股票池和未来结果标签。
- 至少覆盖 20 个完整交易日；快照必须标记 `lookahead_safe=true`，否则结果只能标记为 `lookahead_unverified`。
- 必须同时报告方向命中率、平均收益、累计收益、最大回撤、覆盖率、拒绝率和换手率。
- 缺失未来结果只能降低 coverage，不能当作正确或盈利。
- 不得在回放过程中联网获取当前报价，也不得用未来财务/行情回填历史快照。

## 2. 影子运行

- 至少连续 5 个交易日记录 baseline/candidate 的逐股差异。
- 影子结果只写差异报告，`paper_execution_enabled` 必须为 `false`，不得驱动模拟成交。
- 每日复核新增、移除、方向变化、分数变化和证据变化；候选数量异常、同分率异常或零证据深度分析都要阻断晋级。

## 3. 晋级条件

只有同时满足以下条件，candidate 才能申请接管模拟盘：

- 回放快照完整且 `lookahead_safe=true`；
- 没有 P0 数据、证据、版本追踪或交易因果性失败；
- 相比 baseline，收益和最大回撤不能出现未经解释的恶化；
- 命中率、覆盖率和拒绝率的变化有足够样本支持，不能只看单日或少量股票；
- 影子运行没有未解释的方向翻转、证据丢失或执行资格异常。

任何条件不满足，都保持研究展示和 fail-closed，不降低阈值来制造交易。
