## 五、**核心未知数（新会话第一件事）**

**数据补齐之后，深度模型会不会给出 Buy？**

### 已做的一次真实运行（2026-09-19 14:16）

触发方式（注意前缀是 `/api/v1`）：
```
POST http://localhost:8889/api/v1/ai-os/run-pipeline?force_reanalysis=true
```
`force_reanalysis=true` 会绕过当日深度缓存、真实调用模型，**但不执行纸面交易**。

**结果：没能回答，因为 Codex 账户额度用尽。**

```
deep_analysis_errors = [{"error": "Codex CLI unavailable: Codex CLI failed with
  exit code 1: You've hit your usage limit. Upgrade to Pro ... or try again at 5:58 PM."}]
```

运行本身完全正常：5210 只扫描 → 302 决策 → **98 只具备深度分析资格** → 5 只被选中 → 0 代码错误，耗时 308 秒。5 次调用全部因额度失败，`deep_analysis_count = 0`。

**重试时机**：当天 17:58 之后，或周一开盘的定时扫描。

### 但历史数据回答了一个相关问题

`deep_analysis_attempt` 表（每日尝试 / 成功 / 失败 / 超时）：

| 日期 | 成功 | 失败 | 超时 |
|---|---|---|---|
| 09-19 | 0 | 5 | 0 ← 额度用尽 |
| 09-18 | 7 | 8 | 0 |
| 09-17 | **15** | 0 | 0 |
| 09-16 | 5 | 5 | 5 |
| 09-15 | **20** | 0 | 0 |
| 09-14 | **25** | 0 | 0 |
| 09-13 ~ 09-09 | 10~15/天 | 0 | 0 |

**深度分析在 09-08 ~ 09-18 期间成功了 139 次，而 `strategy_decision.deep_rating` 里没有出现过一次 `Buy` 或 `Overweight`** —— 全是 `Hold`（约 90%）和 `Underweight`（约 10%）。

也就是说：**在数据补齐之前，模型看过证据后选择的是 Hold。这是模型的判断，不是管道故障。** 数据补齐（财务证据）之后会不会改变这个判断 —— 仍是未知数，需要额度恢复后重跑一次。

**注意 `deep_analysis_attempt.status` 的取值是 `success`/`failed`/`timeout`，不是 `available`** —— 用错值会得出"从未成功过"的错误结论。

### 用 DeepSeek 跑了一次（2026-09-19 14:27）

**`DEEPSEEK_API_KEY` 是存在的** —— 它是 **Windows 用户级环境变量**（长度 35），不在 `.env` 里。`settings` 能读到。同一批用户级变量里还有 `ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic`，这就是为什么环境元数据会显示 deepseek。

原来的"硬编码 provider"已修（提交 `b8aa002`）：`pipeline_runner.py:429` 和 `codex_stock_analyzer.py:517` 改为读 `settings.AI_PRIMARY_PROVIDER`。默认值仍是 `codex_cli`，**生产行为不变**。

运行方式：从能读到密钥的 shell 里直接跑脚本（绕开服务进程的环境继承问题），设 `AI_PRIMARY_PROVIDER=deepseek`，写生产库、不执行交易。

**结果：4 次尝试只有 1 次成功**（其余为 `ConnectTimeout endpoint=api.deepseek.com:443` 和空响应 —— 端点从本机不稳定）。

那 1 次的评级：

```
600835.SH   rating = Underweight    direction = sell
            technical_score = 65.4  deep_score = 38.0
            provider = deepseek     model = deepseek-v4-flash
```

**DeepSeek 也给了 Underweight，不是 Buy** —— 与 Codex 那 139 次成功分析的结论一致。

**注意**：只有 1 个样本、且是与系统设计不同的模型，**只能作参考、不能当结论**。买入闸门（`trading_policy.py:174-176`）本来就会拒绝非 Codex 的深度评级，所以这条路也无法产生买入。
